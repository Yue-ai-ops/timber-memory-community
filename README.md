# 童年的木材厂 · 共创资料地图

和老朋友一起，从照片、地图标注和故事中还原童年的街巷。

这个仓库提供共创网页与资料权限结构。**真实照片、住户备注、卫星底图、人物参考与模型原件不在公开仓库内。**

## 伙伴怎么参与

用微信打开网页，输入群内邀请口令，填一个熟悉的称呼，就可以点地图、上传照片、写故事。不需要 GitHub 或邮箱账号。公开代码用于开发合作，素材只在内部资料库中流转。

网页入口：https://timber-memory.pages.dev 。已通过桌面浏览器的口令加入、地图点选、私有照片提交与刷新恢复验证；国内微信访问尚未通过真机验收。微信小程序尚未上线。

## 开发与部署

Node.js 22 或更新版本：`npm ci`、`npm test`、`npm run build`。
Cloudflare Pages 的构建命令为 `npm run build`，输出目录 `dist`。

执行 `supabase/schema.sql` 后启用 Supabase Anonymous Sign-ins。匿名登录仅生成设备身份，必须兑换有效邀请并加入成员名单才能查看内部资料。初始管理员需由项目所有者在数据库中指定，浏览器不能自行升权。

`web/config.json` 只允许写 Supabase 项目 URL 和 **publishable key**；不能放数据库密码、service_role 或 secret key。公开构建采用文件白名单，拒绝复制本机 `private-data`。

## 当前功能

- 地图位置与建筑编号关联，允许位置未知的资料。
- 新旧影像分类、年份与位置分别核对。
- 图片、短片、故事、纠错与补拍意愿提交。
- 本机草稿、上传失败重试、重复文件去重。
- 内部伙伴 / 仅本人和整理者两种可见范围。
- 整理者审核；带版本检查，正式地图不会被自动覆盖。
- GLB 模型预览接口；实际模型由私有资料渠道提供。

### 伙伴标注更新

- 依次安装 `backend/schema.sql`、`backend/002-photo-annotations.sql`。已有项目只执行第二份。
- 投稿署名由服务器绑定成员称呼。称呼是群内自报名称，不是实名认证；换设备可能产生独立身份。
- 新照片和旧资料统一进入档案。上传可填共同分类和来源，之后逐张补名称、年代、地图位置、故事与确定程度。
- 每位伙伴单独保存一份标注；修改只更新本人记录并检查版本，不覆盖其他人的说法，不自动修改正式地图。
- 整理者可查看桶容量。电脑 Chrome/Edge 可选目录备份原件、标注、投稿和地图清单，逐文件检查 SHA-256；不删除云端文件，不表示已建立自动归档。
- 当前未实现服务端缩略图和 Live Photo 配对：原件按上传文件保留；苹果选图可能只提供静态图，完整实况需要照片及 MOV 两份原件。
- 国内微信端的网络与文件选择仍需真实手机验证。
